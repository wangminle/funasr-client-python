# Assets 目录

本目录存放 Skill 所需的测试资源文件。

## 文件清单

| 文件名 | 用途 | 说明 |
|--------|------|------|
| `test-for-speed.mp3` | 速度测试默认音频 | 由用户提供，建议 5-30 秒的短音频 |

## 注意事项

- 如果 `test-for-speed.mp3` 不存在且未通过 `--audio` 指定其他音频，速度测试脚本将返回错误提示，建议联系 Skill 作者
- 用户也可以通过 `--audio` 参数指定自己的音频文件进行速度测试
- 音频文件不能为空（0 字节），脚本会在发送前校验文件大小
